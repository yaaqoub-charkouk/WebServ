Typical webserv structure (high-level)

Config parsing

Read config → build servers, locations, routes, limits.

Networking

Socket setup → bind/listen → accept clients.

Event loop

poll() drives non-blocking read/write for all fds.

HTTP parsing

Request line, headers, body (incl. chunked if supported).

Routing

Match host/port → server → location → method rules.

Response

Status line + headers + body, errors, redirects, autoindex.

CGI

Build env, spawn process, connect stdin/stdout, collect output.

Sessions

Cookie parsing/setting, persistence strategy, expiry.
