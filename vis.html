Project Overview

Project Information HTTP Server

WebServ is a custom HTTP server implementation developed as part of a school project (42 Network curriculum). The project aims to create a production-like web server similar to NGINX, supporting configuration file parsing, multi-port listening, HTTP request handling, and CGI execution.

Final Verdict

Overall Compliance Score

42/100
❌ FAIL

The WebServ project demonstrates solid foundational architecture with proper socket handling, configuration parsing, and response building. However, the core HTTP request handling pipeline is fundamentally broken. The server cannot properly parse incoming requests, route them, or return dynamic responses. The RequestHandler and CGI systems exist but are completely disconnected from the main flow. This is a significant amount of integration work away from a functional HTTP server.

🔧 Top 3 Things to Fix Before Submission

  1. Implement HTTP Request Parsing - Complete HttpRequest::parse() to extract method, URI, headers, and body from raw request string. This is blocking all request handling.
  2. Integrate Request Handler into Server Flow - Modify writeToClient() to call RequestHandler::handleRequest() with parsed HttpRequest data instead of hardcoding index.html responses.
  3. Fix HTTP Protocol Compliance - Change response version from HTTP/1.0 to HTTP/1.1, implement proper keep-alive handling, and add virtual host selection based on Host header.
