💡 How rdbuf() works

// rdbuf() returns the internal buffer of the ifstream // The << operator reads ALL bytes from it into the stringstream // This is the most efficient way to read an entire file in C++98 std::ifstream file("test.conf"); std::stringstream buffer; buffer << file.rdbuf(); // Entire file → buffer std::string content = buffer.str(); // buffer → string

📝 Before / After Example

✅ AFTER (comments stripped)

💡 Key detail: The \n at the end of each comment line is preserved. This is critical because skipWhitespace() uses \n to track line numbers during tokenization.

Stage 3: tokenize() State Machine

stateDiagram-v2 [*] --> SkipWhitespace: Start / reset pos SkipWhitespace --> CheckChar: Done skipping CheckChar --> [*]: pos >= size (end) CheckChar --> EmitSemicolon: char == ';' CheckChar --> EmitOpenBrace: char == '{' CheckChar --> EmitCloseBrace: char == '}' CheckChar --> ReadingWord: isWordChar(char) CheckChar --> ErrorState: unexpected char EmitSemicolon --> SkipWhitespace: addToken(SEMICOLON), advance() EmitOpenBrace --> SkipWhitespace: addToken(OPEN_BRACE), advance() EmitCloseBrace --> SkipWhitespace: addToken(CLOSE_BRACE), advance() ReadingWord --> ReadingWord: isWordChar(next) → word += char ReadingWord --> SkipWhitespace: !isWordChar → emit TOKEN_WORD ErrorState --> [*]: throw LexerException

⚡ skipWhitespace() — Line & Column Tracking

void Lexer::skipWhitespace() { while (pos < content.size() && isWhitespace(currentChar())) { if (currentChar() == '\n') { ++line; // ← Move to next line column = 0; // ← Reset column (advance() will make it 1) } advance(); // ← Always: ++pos, ++column } }

When \n is encountered: line++, column = 0. Then advance() does column++ making it 1. So the next character starts at column 1 of the new line. ✅

📖 readWord() — Accumulating Word Characters

Token Lexer::readWord() { size_t startLine = line; // ← Save position BEFORE reading size_t startColumn = column; std::string word; while (pos < content.size() && isWordChar(currentChar())) { word += currentChar(); // ← Accumulate characters advance(); // ← Move forward } // Stops when: whitespace, ';', '{', '}', or EOF return Token(TOKEN_WORD, word, startLine, startColumn); }

Key Observations

  • http://example.com is a single WORD token (because :, /, . are all word chars)
  • 127.0.0.1 is a single WORD — dots are word chars
  • / alone is a WORD — slash is a word char
  • Empty lines (5, 8, 10...) are simply skipped by skipWhitespace
  • TOKEN_END is always the last token
